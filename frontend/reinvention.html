Under the hood

The stack is not the story. But here it is.

The agent runs on a lean open-source infrastructure stack at ~€50/month. The architecture is deliberately simple — a PoC that proves the pattern, not the production system.

Full architecture breakdown →
Data
569M vehicle records from BASt open data (Jan–Jun 2026), stored as Parquet on S3 in Apache Iceberg v2 format. Queried live by DuckDB over httpfs — no data warehouse, no ETL pipeline, no cluster to manage.
Agent
Claude Haiku via Amazon Bedrock Converse API, running an agentic tool-use loop. The agent decides when to call execute_sql, writes the SQL, runs it, reads the result, and synthesises the answer — all within a single streaming response.
API
FastAPI on ECS Fargate behind an ALB and CloudFront HTTPS endpoint. The /api/ask endpoint streams Server-Sent Events back to the browser — so the answer appears token-by-token, like a conversation.
CI/CD
GitHub Actions builds the Docker image, pushes to ECR, and deploys to ECS on every push to api/. The frontend deploys to S3 static hosting. Zero manual deployment steps.
